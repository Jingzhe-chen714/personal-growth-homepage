# Ti60 实时视觉与串口控制：公开项目说明

项目时间：2026年9—10月。状态：已完成。记录更新：2026-11-15。

## 项目与个人职责

这是一个连接电脑控制、FPGA视觉处理和显示输出的团队项目。系统整体包含图像处理与串口控制；我负责电脑端串口界面，并参与设备联调和显示问题的观察、处理。视觉算法与板端工程属于团队整体成果。

## 配置记录

- Ti60 FPGA板卡及匹配的视觉工程。
- 显示器与电脑端控制界面。
- 后续购买并加入分配器、采集卡，补充原有硬件配置。

本文记录功能关系与处理经历；设备型号、接口与具体接线对应将继续补充。

## 故障现象与处理结果

| 观察位置 | 原配置下的现象 | 处理后的记录 |
| --- | --- | --- |
| 显示器 | 输出正常 | 继续作为显示观察的对照 |
| 电脑端 | 严重卡顿，长时间工作后黑屏 | 购买并加入分配器和采集卡后，同步显示问题解决 |

这次联调表明，显示器正常并不意味着电脑端显示链路也正常。排查时需要分别记录两个观察位置的表现。原有板卡资源与硬件配置不足以支撑预期的同步显示，后续通过增加上述设备完成配置调整。

## 再次搭建时的检查清单

1. 对照实际设备说明确认连接，先检查显示器是否正常输出。
2. 启动电脑端控制界面，使用项目记录中的串口参数连接设备。
3. 发起控制操作，同时观察显示器和电脑端界面是否有响应。
4. 连续运行并记录是否再次卡顿或黑屏，保存开始、结束时间与异常现象。

以上是复现与后续记录的检查方法。本文不填写未保留的具体帧率、延迟或稳定运行时长。
